StreamWeaver 🚀

High-Throughput No-Code ETL Pipeline

StreamWeaver is a web-based ETL pipeline that allows users to upload CSV datasets, clean and transform data, validate data quality, preview processed records, and download the processed dataset.

✨ Key Features

- 📂 CSV Dataset Upload
- 🧹 Remove Empty Rows
- ✂️ Trim Spaces
- 🔢 Automatic Number Conversion
- ✅ Data Validation
- 📊 Dataset Statistics
- 🧩 Dataset Schema Detection
- 👀 Processed Data Preview
- 📥 Download Processed CSV
- ⚙️ Configurable Pipeline Controls

🛠️ Tech Stack

Frontend: React, Vite, JavaScript, CSS

Backend: Node.js, Express.js, Multer, CSV Parser, CORS

🔄 ETL Pipeline

"Upload CSV → Extract → Validate → Transform → Preview → Download"

▶️ Run Locally

Backend

cd backend
npm install
node server.js

Backend runs on "http://localhost:5000"

Frontend

cd frontend
npm install
npm run dev

Frontend runs on "http://localhost:5173"
